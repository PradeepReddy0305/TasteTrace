# 🍽️ TasteTrace

> A clean, lightweight, and fully responsive recipe discovery web application built strictly with **Vanilla HTML, CSS, and JavaScript** — featuring zero frameworks or complex build tools.

## ✨ Key Features

* **🍳 Category & Meal Type Discovery:** Automatically groups recipes by meal type (Breakfast, Lunch, Dinner, Snack, etc.) with intuitive card layouts.
* **🔍 Live Search Engine:** Instantly search through recipes by name or ingredients without page reloads.
* **📱 Multi-Page Architecture:** Clean routing separated across 3 dedicated pages (`Home`, `Recipe Detail`, and `Favorites`) using URL query parameters (`?id=`).
* **☑️ Interactive Ingredient Checklists:** Check off ingredients as you prep your meals.
* **⭐ Persistent Favorites:** Save your go-to recipes locally using the browser's `localStorage`.
* **🎨 Modern UI/UX:** Styled with custom CSS, dark-mode aesthetics, responsive grids, and gradient typography.

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Grid, Flexbox, Custom Variables)
* **Logic:** Vanilla JavaScript (ES6+ async/await, DOM manipulation)
* **Data Source:** [DummyJSON Recipes API](https://dummyjson.com/recipes)
